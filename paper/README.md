# Paper source

LaTeX source of the SAGE-v2 manuscript. The compiled PDF is **not** stored
in this repository — it is published on the GitHub [Releases](../../releases)
page together with the journal-submission bundle.

## Compile

```bash
# body (18 pages, anonymous, figures resolved via ../figures/)
tectonic -X compile main.tex

# with the cover page (produces final.pdf, 19 pages)
python build/merge_final.py
```

`build/cover.html` is the cover source rendered by `html2poster`; adjust
authors/affiliation there and in the title block of `main.tex` before use.

## Files

- `main.tex` — master file (title block, macros, section inputs)
- `sec1_intro.tex` … `sec8_conclusion.tex` — sections
- `tab_main.tex`, `tab_needle.tex`, `tab_sens.tex`, `tab_compliance.tex` —
  table bodies (regenerated from `../results/` by `../scripts/gen_tables.py`)
- `references.bib` — bibliography (21 entries, venue-verified)
- `../figures/fig_*.pdf` — vector figures (regenerated by
  `../scripts/make_figures.py`)

The author block is a placeholder (`Anonymous`); fill in real author data
before journal submission.

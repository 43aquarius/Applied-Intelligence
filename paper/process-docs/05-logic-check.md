# 逻辑检查 prompt 应用日志

「逻辑检查」prompt 要求：高容忍度红线审查，只报阻碍理解的问题。

## 审查方式

自动化一致性核对（scripts/logic_check.py，可复跑），共 33 项：

1. 数值一致性（论文声明 vs 研究记录 CSV）
   - 摘要/引言/表格/正文分析的 20+ 个关键数字全部与
     ppl_compression / needle / efficiency / longbench / ablation /
     gate_variants / capacity CSV 逐一对账。
   - 跨文件消融数字闭环：LABA 差 0.35、decay 差 0.28、
     recency=StreamingLLM@20%（15.98）等。
2. 交叉引用完整性：所有 \ref 均有 \label；所有 \cite 键均在
   references.bib 中（37/37 双向闭合，无死链、无孤条目）。
3. 术语一致性：SAGE 全文 69 次；全名 5 处均为结构位
   （标题/页眉/元数据/首次定义/注释）。
4. 章节声明与实验闭环：引言三条贡献的数字、摘要五句的数字、
   结论的总结数字均可在表格中找到出处。

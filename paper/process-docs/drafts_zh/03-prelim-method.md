# 中文草稿：预备知识 + 方法

## 3 预备知识与问题形式化

### 3.1 自回归解码与 KV 缓存

设解码器仅有 L 层，每层 H 个注意力头，头维 d_h。第 t 步生成时，查询 q_t 与历史键 K_{1:t} 计算注意力，SoftMax(QK^T/√d)V 读取历史值。为避免重算，每层缓存 (k_i, v_i)。fp16 下每 token 每层占 2·d_h·H·2 = 4d 字节（d=H·d_h 为模型维），7B 模型每千 token 约 0.065GB。显存随 t 线性增长，且 prefill 后的注意力读取成本也随 t 增长。

### 3.2 预算约束下的逐出

给定全局保留率 ρ ∈ (0,1]，缓存策略维护保留集合 C_l^t ⊆ {1..t}（每层），满足 Σ_l |C_l^t| ≤ ρ·L·t 的显存契约。条目一旦逐出不可恢复。逐出策略的目标是最小化与完整缓存的质量差距。我们将该目标具体化为两个可测量指标：困惑度增量 Δppl 与下游任务/检索的保持率。已有方法将 |C_l^t| 设为相同的 ρ·t；本文放宽为逐层预算 b_l(t)，仅约束总和。

### 3.3 三个失效模式的形式刻画

(i) 层间注意力分布集中度差异：定义层 l 的饱和度 κ_l 为该层平均注意力分布的归一化熵（除以 log t），κ 小表示注意力集中于少数位置，少量条目即可近似该层注意力；(ii) 分数陈旧性：累计分数 s_i 在话题漂移后仍保持高位；(iii) 局部性破坏：最近条目对局部注意力模式（归纳头、位置邻近）关键，纯重要性逐出丢弃它们会破坏检索。SAGE 的三个组件分别对应 (i)(ii)(iii)。

## 4 SAGE 方法

### 4.1 总览

SAGE 在解码循环中在线运行：每步用注意力输出更新置信度；每 K=512 步重算层预算；当某层缓存超过 b_l 时触发逐出，仅从历史储水池逐出最低分条目。图 1 给出架构与数据流。设计原则有二：所有信号复用已有的注意力计算，不增加对完整缓存的额外读取；一切元数据（分数数组、桶结构）只占受控字节的极小部分。

### 4.2 注意力置信度评分（ACS）

对层 l 的条目 i，第 t 步其获得的注意力为 a_t^l(i)（对该层所有头求均值）。置信度分数指数衰减累计：
s_i^l(t) = λ·s_i^l(t-1) + a_t^l(i)，λ∈(0,1)。
前 r 个最近条目与 |S| 个注意力槽位免于评分逐出。λ=1 退化为 H2O 式静态累计。λ 体现"即时相关性优先"：λ^k 步前的注意力贡献衰减为 λ^k，话题漂移后旧高分自然让位。每条目每步更新为 O(1)（一次乘加），分数数组每层每 token 仅 4 字节，占缓存字节的比例为 1/d，7B 模型约 0.02%。

### 4.3 层自适应预算（LABA）

以 κ_l（归一化注意力熵）为饱和度信号。层预算按
b_l = ρ·t · (κ_l/κ̄)^τ / clip
分配，τ=1.5 控制对比度，clip 将 b_l 限制在 [b_min·t, t]，κ̄ 为层间均值。κ_l 每 K 步在近期窗口上估计（复用注意力统计，不额外读取缓存）。求和恒满足 Σ b_l ≤ ρ·L·t，故显存契约保持。深层注意力集中 → κ 小 → 预算小；浅层弥散 → κ 大 → 预算大。第 5 节的图 3 显示 LLaMA-2-7B 在 20% 全局契约下呈漏斗形分布：前四层保留 0.55，末四层仅 0.06。

### 4.4 双储水池逐出（DRE）

每层缓存划分为：受保护最近窗口 R（|R|=r，先进先出）∪ 注意力槽位 S（永久驻留）∪ 历史区 H_l（按 b_l - r - |S| 容量选择）。逐出触发时（|C_l| > b_l），从 H_l 中移除最低置信度条目。实现用分桶最小堆：分数按 2^k 区间分桶，桶内无序，均摊 O(1) 逐出。该结构保证最近条目永不被逐出（回应失效模式 iii），且槽位保护复用 StreamingLLM 的观察。

### 4.5 算法与复杂度

算法 1 汇总解码循环。每步成本：评分 O(1)/条目；逐出均摊 O(1)（分桶堆）；预算重算 O(L)。对比完整注意力每步 O(t·d)，评分开销可忽略。附加显存：分数数组 4L 字节/token（≈0.02% of cache bytes for 7B）+ 桶结构稀疏数组。实测 20% 契约下总元数据与保护窗口带来 2.6 个百分点的超额（0.47GB vs 理想 0.42GB @32K），论文如实报告。

### 4.6 实现

SAGE 以 PyTorch hook 实现，替换 KV 缓存管理的 gather/scatter 路径；注意力核使用 FlashAttention-2，评分读取其返回的注意力统计（LSE 近似重建每条目注意力通量——实现上每步仅对 top-k 条目精确累计，其余以常数预算近似）。与量化（KIVI）正交，可叠加。

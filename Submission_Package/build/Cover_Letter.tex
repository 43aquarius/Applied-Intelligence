\vspace{0.6em}

\noindent\textbf{Research problem.} Long-context inference of large
language models is bounded by the key-value (KV) cache, which grows
linearly with context and exhausts accelerator memory well before
compute does. Existing training-free eviction methods lose quality
quickly once the cache is reduced below roughly half of its full size,
which prevents aggressive memory savings in deployment.

\vspace{0.6em}

\noindent\textbf{Method.} The manuscript proposes SAGE, a training-free
framework that formulates KV cache eviction as a global
memory-contract constrained allocation problem and couples three
mechanisms under that single contract: an exponentially decayed
attention-confidence score that tracks the current relevance of each
cached entry, a layer-adaptive budget allocator that re-allocates cache
capacity online according to measured attention saturation, and a
dual-reservoir structure that protects the recent window and attention
sinks while evicting only from the history region.

\vspace{0.6em}

\noindent\textbf{Main contributions.} (i) The unified
memory-contract formulation with online, entropy-driven layer budgets,
which no cited prior component provides; (ii) the decayed-confidence
scoring rule with the protected reservoir, whose separate and combined
values are priced in a one-at-a-time ablation; (iii) an evaluation
covering language quality, long-context tasks, retrieval to 128K
tokens, and wall-clock efficiency on LLaMA-2-7B/13B-Chat and
Vicuna-13B.

\vspace{0.6em}

\noindent\textbf{Key findings.} At a nominal 20\% cache budget, SAGE
holds WikiText-2 perplexity within 0.34 points of the full cache
(5.46 against 5.12 on the 7B model), retains 98.0\% of the LongBench
average, and reaches 94.8\% needle-retrieval accuracy at a 128K
context. The realized footprint is 22.6\% of the full cache including
all bookkeeping. At 32K tokens the KV memory shrinks by a factor of
4.4 and decode throughput rises by 1.52$\times$, growing to
2.02$\times$ at 128K, which extends the context capacity of a 24~GB
GPU from 17K to 74K tokens.

\vspace{0.6em}

\noindent\textbf{Relevance to Applied Intelligence.} The work targets
the applied side of intelligent systems: it is a deployable,
training-free mechanism that converts a hard memory constraint into a
controllable quality-memory-throughput trade-off, and its contribution
is an efficient inference technique for large language models running
under practical hardware limits. I believe this fits the journal's
scope of original intelligent-systems methodology addressing
resource-constrained real-world deployment.
